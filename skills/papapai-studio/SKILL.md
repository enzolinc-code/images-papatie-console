# 趴趴立牌工作台

使用本项目本地网页进行人物生图、发丝抠图、保真场景合成和成品分配。先确定仓库实际路径；不假定某盘符、用户名或Python安装位置。启动与配置见仓库根目录 README.md。

- 工作台入口 `launch.py`；安装入口 `setup.py`。环境配置仅在本地 `.env` 和 `config.json`，不要把密钥写入提示词或输出。
- 八个pose ID保持稳定：chin、both、edge、heart、wave、cross、lean、pillow。按需读 [姿势提示词](references/pose-prompts.json)，每种动作独立生成、逐图检查后替换，保留旧图备份。
- 人物图只要完整上半身、双臂双手，发饰/袖口/指尖不裁断；透明PNG必须有真实alpha，不能用棋盘格冒充。
- chin是一手托腮另一手垂落；both为双掌托腮；lean为头侧倾且一手支撑；pillow必须脸颊直接枕在低位前臂上，两手都低位。heart的小指心由拇指与食指交叉形成，不增加心形图标。
- 场景默认优先保真合成：标定承托线与四角，只对原PNG整体透视合成。不要让AI重新画已有立牌的脸、手指与动作。旧立牌背景先清理并确认，再批量复用模板。
- 用户明确选通道时固定该通道；未指定时沿用工作台选择/项目配置。密钥未配置或请求状态不明时停止，保留成功原图，避免自动重复付费或换通道。
- 提示词中的素体线稿仅用于姿势示意；制作实际商品图时以用户上传人物的面貌、服装、配饰为依据。
- 上线图需逐张目视检查解剖、姿势区别、发丝/指缝、画布完整性；生成全套预览。上传GitHub前用根目录 `scripts/release_check.py` 验证文件范围，排除密钥和个人素材。

图库及内置AI图来源/许可见根目录 THIRD_PARTY.md。用户的个人非商业使用确认不能扩展成图库商业授权。
