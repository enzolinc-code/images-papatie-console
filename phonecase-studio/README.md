# 多刀模手机壳工作台

HTML界面与本地图片处理服务，支持上传刀模、素材排版、透明PNG导出及三条可配置生图通道。

## 运行
1. 安装Windows 64位Python 3.11或更新版本，运行`安装运行环境.ps1`。
2. 双击`打开手机壳工作台.vbs`。首次会从`config.example.json`创建本机`config.json`。
3. 上传刀模及图片即可排版下载。刀模支持PNG/JPG/WebP闭合红线或透明实心蒙版，不支持PDF/DXF/SVG。
4. AI为可选功能。使用前在本机config.json填写对应接口地址与模型，密钥通过Windows用户环境变量配置。

## 接口配置
仓库不包含任何真实API地址、密钥、代理地址、付费账号配置、个人路径或本机模型预设。
通道3使用兼容图片编辑接口，通道4保留媒体任务接口适配，通道5保留异步图片任务适配。需选择适合对应协议的服务，不能假定任意API兼容所有通道。
变量名：通道3 CODEX_API_KEY/CODEX_API_URL；通道4 CHANNEL4_API_KEY/CHANNEL4_API_URL；通道5 IMG4_API_KEY/IMG4_API_URL。可选代理CHANNEL4_PROXY/IMG4_PROXY默认不设置。
通道3及通道4非媒体模型分支需要用户另行安装可信图片CLI，放在`tools/codex-image2-windows-amd64.exe`；二进制不随仓库分发。CLI需支持edit、--image、--mask、--max-attempts等参数。
没有接口配置时仍可进行手工排版和PNG下载。不要把config.json、密钥或日志提交到Git。

## 使用
左侧上传刀模及素材，中间拖动预览，右侧缩放/旋转/镜像/排版与下载。可导出完整图案、透明印刷PNG、白底预览。
保留模式会恢复不透明原图区；已铺满壳面时不额外调用AI。AI结果需要检查主体、凹口和补图接缝，不保证生成结果自动达到送印标准。
任务保存在data/jobs，成品保存在成品目录。刷新仅查询原任务，不自动重新提交。每次生成1张，不自动切换通道。
本服务仅监听本机回环地址，修改请求需同源与本机会话令牌；请勿直接暴露公网。
刀模像素尺寸不等于毫米规格，送厂前核对物理尺寸、色彩及出血要求。
